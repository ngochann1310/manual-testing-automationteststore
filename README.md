# Automation Test Store - Manual Testing Project

This repository showcases a comprehensive **Manual Functional Testing** project conducted on the **Automation Test Store**, a simulated e-commerce platform. It demonstrates the end-to-end software testing process, including requirement analysis, test case design, manual test execution, defect reporting, and issue management using **Jira Cloud**.

# Project Overview

The project focuses on validating the core functionalities of an e-commerce website from an end-user perspective. The testing process covers the complete software testing lifecycle, from designing test cases to executing tests, documenting defects, and managing issues using Jira.

The objective is to verify that the system satisfies functional requirements while providing a reliable and consistent user experience.

---

# Objectives

- Apply Black-box Testing techniques, including **Equivalence Partitioning (EP)** and **Boundary Value Analysis (BVA)**.
- Design comprehensive manual test cases covering both valid and invalid scenarios.
- Execute manual testing using **Microsoft Edge**.
- Identify, document, and manage software defects using standardized Bug Reports and Jira Cloud.
- Evaluate the stability and functionality of critical e-commerce workflows.

---

# Project Scope

The testing scope covers the major customer-facing features of the Automation Test Store, including:

- User Registration
- User Login
- Checkout Process
- Order Tracking
- Contact & Support

The project focuses exclusively on **functional testing** of the web application.

---

# Testing Activities

### Test Planning
- Analyze functional requirements.
- Define testing scope and strategy.

### Test Case Design
- Design **110 manual test cases** using EP and BVA techniques.
- Cover both positive and negative scenarios.

### Test Execution
- Execute all test cases manually using **Microsoft Edge**.
- Record actual results and execution status.

### Defect Reporting
- A total of **40 test cases failed** during execution.
- Among them, **24 representative defects** were formally documented in the Bug Report and managed through Jira Cloud.

### Test Documentation
- Organize testing artifacts for project documentation and portfolio presentation.
