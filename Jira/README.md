================================================================================
                             JIRA PROJECT OVERVIEW
================================================================================

This project utilizes Jira Cloud as the central management tool for the software 
testing lifecycle of the Automation Test Store website, an e-commerce simulation 
platform. Jira was employed to organize the testing scope into high-level Epics, 
track individual Test Cases as issues, and manage the Defect Lifecycle for bugs 
identified during manual execution.


--------------------------------------------------------------------------------
JIRA FEATURES DEMONSTRATED
--------------------------------------------------------------------------------
The following Jira features are evidenced through the project documentation and 
screenshots:

* Project Management: Centralized tracking under the "Project Automation Test Store" 
  workspace.
* Epic Management: Organization of testing into functional blocks: User 
  Authentication, Checkout Process, and Contact & Support.
* Issue Tracking: Granular management of bugs and tasks with unique IDs (e.g., 
  PAT-14, PAT-15).
* Bug Tracking: Detailed logging of defects including environment, steps to 
  reproduce, and attachments.
* Sprint Planning: Assignment of issues to specific iterations, such as "PAT 
  Sprint 1 - Authentication".
* Backlog Management: Maintenance of a prioritized list of work items ready 
  for sprint allocation.
* Workflow Management: Tracking issue progress through statuses such as TO DO 
  and IN PROGRESS.
* Assignee & Reporter: Accountability tracking for testing tasks and bug 
  discoveries.
* Priority Management: Classification of issues using standard priority levels 
  (e.g., Medium).
* Story Point Estimation: Quantitative estimation of effort for testing tasks.


--------------------------------------------------------------------------------
TESTING WORKFLOW
--------------------------------------------------------------------------------
The project followed a systematic manual testing workflow integrated with Jira:

1. Requirement Analysis: Analyzing the functional flow of the 
   Automation Test Store website.
2. Test Case Design: Creating scenarios using Equivalence Partitioning and 
   Boundary Value Analysis.
3. Test Execution: Performing manual tests on the Microsoft Edge browser.
4. Bug Reporting: Logging defects in Jira when actual results deviated from 
   expected outcomes.
5. Issue Tracking: Managing the status of reported bugs within the Jira 
   board/list.


--------------------------------------------------------------------------------
PROJECT STRUCTURE
--------------------------------------------------------------------------------
The testing scope was divided into three primary functional modules managed as 
Epics in Jira:

* User Authentication (PAT-27): Covers the Register and Login functionalities, 
  including input validation for names, emails, and passwords.
* Checkout Process (PAT-28): Manages the end-to-end purchasing flow, including 
  adding products to the cart, guest checkout, and order confirmation.
* Contact & Support (PAT-33): Includes the "Contact Us" communication form and 
  the "Check Your Order" functionality for tracking order history.
